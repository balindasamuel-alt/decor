# Deco Events Butembo

Galerie de photos de décoration pour mariages et événements à Butembo.
Projet réalisé par Mushagalusa Balinda Samuel.

## Technologies utilisées
- HTML et CSS
- Cloudinary pour l'hébergement des images
- GitHub Pages pour la publication

## Comment Cloudinary est utilisé
Les images ne sont pas stockées dans le dossier du projet.
Elles sont téléversées sur Cloudinary, et le site les affiche
directement à partir de leurs liens Cloudinary (res.cloudinary.com).

Les 3 images utilisées :
1. https://res.cloudinary.com/if9pcwgf/image/upload/v1794429319/Screenshot_20261111-223053.png.jpg
